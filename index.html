Como instalar o app

Instale este sistema na tela inicial para abrir como aplicativo, sem precisar procurar o site toda vez.

Android — Chrome

  1. Abra o sistema no Google Chrome usando o link do app.
  2. Toque no menu de três pontos ⋮.
  3. Escolha Instalar aplicativo ou Adicionar à tela inicial.
  4. Confirme em Instalar ou Adicionar.

iPhone — Safari

  1. Abra o sistema no Safari.
  2. Toque no botão Compartilhar (quadrado com seta para cima).
  3. Role o menu e toque em Adicionar à Tela de Início.
  4. Toque em Adicionar para confirmar.
Importante: o sistema precisa ser aberto por um link do navegador, de preferência com HTTPS. Não abra somente o arquivo index.html pelo gerenciador de arquivos do celular.
